# Send-Ready Emails

Four .eml files. Each opens in Mail.app on double-click (macOS).

## Before you send
1. Open each .eml in a text editor
2. Replace placeholders in brackets:
   - [counsel-email@firm.com] -> real address
   - [your-email@company.com]  -> your address
   - [Counsel name] / [Vendor contact] / [Identity team] / [Data owner]
   - [Name] / [Title]          -> your name and title
   - [date]                    -> proposed timeline
3. Attach the referenced document(s):
   - Email 1: attach 01_legal_review_brief.md and 02_regulatory_checklist.md
   - Email 2: attach 03_pentest_scope_of_work.md
   - Email 3: attach 04_idp_swap_guide.md
   - Email 4: attach 05_data_owner_signoff.md
4. Double-click to open in Mail, review, send
